REST API Reference
Base URL: http://localhost:3000/api  ·  All responses are JSON  ·  No auth required
GET/api/health
Server health check. Returns uptime, version, total scan count.
POST/api/scan
Log a single scan result. Body: { age, gender, genderConfidence, facesDetected, sessionId }
POST/api/scans/batch
Log multiple scans at once. Body: { scans: [...], sessionId }
GET/api/scans?page=1&limit=20&gender=male
Paginated scan history. Filter by gender or sessionId.
GET/api/stats
Analytics: total scans, avg/min/max age, gender counts, age group breakdown.
POST/api/session
Start a new scan session. Returns a session ID to attach to subsequent scans.
GET/api/session/:id
Get stats and scan log for a specific session.
DELETE/api/scans
Delete all scan history from the server.
